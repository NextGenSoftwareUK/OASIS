Using @oasisomniverse/web6-api
This demo loads the npm package via esm.sh. The same code runs in Node.js or any bundler.
Install
npm install @oasisomniverse/web6-api
AI Completion with BRAID
import { Web6Client } from '@oasisomniverse/web6-api'; const web6 = new Web6Client({ baseUrl: 'https://dev.api.web6.oasisomniverse.one' }); web6.setToken('<your-oasis-avatar-key>'); const { result } = await web6.completion.complete({ Provider: 'auto', Model: 'auto', Messages: [{ Role: 'user', Content: 'Your prompt here' }], UseHolonicBraid: true, // Generator/Solver split — 74× cost reduction UseFAHRN: true, FahrnTaskType: 'general', Routing: { Priority: 'cost', Fallback: true }, }); console.log(result.content); console.log(`$${result.estimatedCostUSD} via ${result.provider}/${result.model}`);
FAHRN Multi-Agent Dispatch
const { result } = await web6.fahrn.solve({ problem: 'Design a zero-downtime Postgres migration for a 50M-row table', taskType: 'architecture', mode: 'Parallel', // Serial | Parallel | Debate | Voting | Decomposed maxTotalTokens: 8000, maxCostUsd: 0.50, }); console.log(result.answer); console.log('Agents used:', result.agentsUsed); console.log('BRAID graph reused:', result.braidGraphWasReused);
OpenServ Provider — one SERV key, all models
// Read OpenServ's live model catalogue (authenticated) const response = await fetch('https://dev.api.web6.oasisomniverse.one/v1/openserv/models', { headers: { Authorization: 'Bearer <your-oasis-jwt>' } } ); const models = await response.json(); // Route a completion through OpenServ const { result } = await web6.completion.complete({ Provider: 'openserv', // GPT-5, Claude, Gemini, Grok, DeepSeek via SERV gateway Model: 'auto', Messages: [{ Role: 'user', Content: 'Hello via OpenServ' }], });
Streaming SSE
