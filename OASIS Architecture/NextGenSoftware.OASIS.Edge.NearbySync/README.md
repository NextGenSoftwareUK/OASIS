# NextGenSoftware.OASIS.Edge.NearbySync

Nearby-device HyperDrive sync for the OASIS Edge Runtime: BLE, LAN/Wi-Fi Direct and multi-hop mesh relay with signed envelopes. Implements `IHyperDriveSyncTransport`, so the Edge runtime's outbox, cursors and conflict handling work unchanged. See `Docs/Devs/EDGE_OFFLINE_MESSAGING.md`.
