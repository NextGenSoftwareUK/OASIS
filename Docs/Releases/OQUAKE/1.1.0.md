# OQUAKE v1.1.0

OASIS-integrated vkQuake client using OGEngineClient and the WEB4/WEB5 services.

## Features and fixes in this release

This initial component release summary covers the released v1.1.0 source, not just the final packaging commits.

### Features

- Shared OASIS/STAR avatar identity, beam-in and automatic sign-in, with token renewal.
- Cross-game inventory for weapons, ammunition, health, armour, powerups and keys; send inventory items to avatars or clans through the connected OASIS services.
- Configurable pickup/storage rules, including keeping surplus items for later use and optional item stacking/minting.
- Cross-game quests with objectives, prerequisites, subquests, progress summaries and an in-game tracker; active quest/objective persistence.
- Background inventory and quest loading through the shared OGEngineClient integration.
- OGLib shared headers and in-game Offline Sync / Sync-and-disable options.

- Monster-kill tracking with XP and configured monster minting integration.
- Inventory (I), quests (Q), active-objective cycling (O), tracker visibility and XP display controls.
- Omniverse Hub pause/portal-arrival integration, 64-bit avatar karma and shared string helpers.

### Fixes and hardening

- Correct cross-game weapon mappings and pickup handling, including false pickups when starting a map.
- Persist and restore the active quest/objective, correct quest-list selection and show loading state while fetching quests.
- Fix quest-popup focus/tab navigation, prevent movement-key interference while the popup is open and restore controls on close.
- Correct Windows popup/font scaling and tracker distortion when the scoreboard is displayed.
- Improve inventory item descriptions, maximum-health/armour feedback, callbacks and JWT renewal.
- Repair Linux builds, portable atomic initialization and browser-launch error reporting.

### Build and packaging

- Windows x64, Linux x64 and macOS ARM64 archives.
- Compile the active OQUAKE integration in Meson and link native OGEngine consistently across toolchains.
- Correct Windows package paths, runner/toolset selection and platform inputs.
- Consume archive listings completely so pipefail does not reject valid archives.
- Both release-fix promotions (#8 and #9) passed their 18 checks; this does not establish exhaustive gameplay or cross-device testing.

## Downloads and requirements

Download OQUAKE-Windows-x64-v1.1.0.zip, OQUAKE-Linux-x64-v1.1.0.tar.gz or OQUAKE-macOS-arm64-v1.1.0.tar.gz from [release assets](https://github.com/NextGenSoftwareUK/OQUAKE/releases/tag/v1.1.0).
Quake game data and appropriate OASIS service configuration are required.
