# ODOOM v1.1.0

OASIS-integrated UZDoom client using OGEngineClient and the WEB4/WEB5 services.

## Features and fixes in this release

This initial component release summary covers the released v1.1.0 source, not just the final packaging commits.

### Features

- Shared OASIS/STAR avatar identity, beam-in and automatic sign-in, with token renewal.
- Cross-game inventory for weapons, ammunition, health, armour, powerups and keys; send inventory items to avatars or clans through the connected OASIS services.
- Configurable pickup/storage rules, including keeping surplus items for later use and optional item stacking/minting.
- Cross-game quests with objectives, prerequisites, subquests, progress summaries and an in-game tracker; active quest/objective persistence.
- Background inventory and quest loading through the shared OGEngineClient integration.
- OGLib shared headers and in-game Offline Sync / Sync-and-disable options.

- Heretic, Hexen and Strife integration support.
- Quest popup tabs, objective selection, progress tracking, quest timer and HUD notifications.
- Quick-use health (C) and armour (F), inventory menu access and configurable automatic health/armour/powerup use.

### Fixes and hardening

- Correct keycard-to-door and cross-game weapon mappings.
- Correct pickup/use behaviour at configured health/armour limits, including feedback when an item cannot be used.
- Persist and restore active quest/objective selection; refresh objective completion and tracker state.
- Reduce quest-list scrolling flicker and improve popup layout.
- Repair automatic beam-in, JWT renewal and background inventory loading.
- Correct configuration format handling and restore missing oasistar.json defaults.

### Build and packaging

- Integrated Windows x64, Linux x64 and macOS ARM64 release pipeline.
- Serialize native OGEngine publishing to avoid concurrent build-output writers.
- Build macOS packages for the runner architecture.

## Downloads and requirements

Download the platform archive from [release assets](https://github.com/NextGenSoftwareUK/ODOOM/releases/tag/v1.1.0).
Windows x64 and macOS ARM64 assets retain upstream UZDoom/alpha naming; the Linux archive is named ODOOM-Linux-x64-v1.1.0.tar.gz.
Game content/IWADs and appropriate OASIS service configuration are required. Published packages do not establish exhaustive gameplay or cross-device testing.
