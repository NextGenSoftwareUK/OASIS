## Competitive Moat

No competitor — Web3 or traditional — comes close to 124 implemented providers under a single unified interface:

| Platform | Providers |
|---|---|
| **OASIS** | **124** |
| Moralis | ~15 (read-only Web3 data) |
| Alchemy | ~10 (EVM chains only) |
| Infura | ~8 (EVM chains only) |
| The Graph | ~50 (indexing only, no write) |
| Chainlink | ~20 (oracle data only) |

OASIS is the only platform that provides **read + write + identity + social + spatial** across all categories through a single hot-swappable provider interface (OASIS HyperDrive).
