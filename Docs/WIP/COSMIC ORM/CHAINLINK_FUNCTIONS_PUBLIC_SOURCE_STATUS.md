# Chainlink Functions public source status

4 November 2026. Chainlink documents Functions deprecation on 15 June 2026
for testnets and 30 June 2026 for mainnets. Its supported-networks page
directs existing subscribers to Chainlink Runtime Environment (CRE).

Keep ChainlinkFunctionsOASIS out of active Functions demo admission.
The retained router addresses can support a separately scoped historical
on-chain read if a bounded historical contract is qualified. CRE requires
its own source identity and migration decision. Existing ChainLinkOASIS
Data Feed evidence applies to the separate feed provider.

[Chainlink Functions supported networks and deprecation](https://docs.chain.link/chainlink-functions/supported-networks)

12 November Cancun time. Chainlink’s published network list identifies the retired Functions routers on Ethereum, Base and Polygon. A read-only preflight requested `eth_chainId` from the documented public RPC for each network. All three returned HTTP 403 before a chain ID, finalized block, bytecode or router-version response could be verified. This is an access observation from the current environment. Historical CQL qualification remains open on a permitted RPC. No router calls, transactions, credentials, local files or runtime installs were made.
