# CQL relationship queries

23 October 2026. Relationship filters select roots before root ordering and paging. They do not request child output. Use WithChildren separately when the response needs a graph.

## Direct children

```csharp
// These two conditions may be satisfied by different direct children.
// Mandatory server access must be bound before composing the query.
var query = CosmicQuery<Holon>.Create()
    .WithReadAccess(trustedAccess)
    .WhereAnyChild(child => child.HolonType == HolonType.Quest)
    .WhereAnyChild(child => child.Name == "coffee")
    .OrderBy(root => root.Name)
    .Take(10);

if (query.IsError)
    throw new InvalidOperationException(query.Message);
```

MongoDB uses a native bounded lookup; SQLite uses correlated EXISTS; Neo4j uses native HAS_CHILD/projection correlation. Current ParentHolonId and canonical role membership must both agree. A declared empty manifest never admits an unlisted child; an explicitly absent manifest uses current parent links. Dangling declarations cannot manufacture children. Each hop applies trusted owner/public access before matching. Reparenting removes the old path, and the new owner must admit membership.

Mongo membership projections are generated by the final native writer, including conditional and replication writes; activation upgrades old projections under exact-record comparison without changing logical revisions. Validation and lookup share the same snapshot. Neo schema3 projections derive membership from canonical snapshots. SQLite validates canonical manifests before testing existence, including empty parents. No provider relies on a stale embedded Children array as query truth.

## Bounded descendants

```csharp
// Depth1 means direct children; the root never matches itself.
var limits = CosmicQueryTraversalOptions.Create(
    maximumDepth: 4,
    maximumNodes: 250);

if (limits.IsError)
    throw new InvalidOperationException(limits.Message);

var query = CosmicQuery<Holon>.Create()
    .WithReadAccess(trustedAccess)
    .WhereAnyDescendant(
        child => child.Name == "coffee",
        limits.Result)
    .OrderBy(root => root.Name)
    .Take(10);

if (query.IsError)
    throw new InvalidOperationException(query.Message);
```

Traversal limits are independent of maxChildDepth/output budgets. All visible canonical nodes within the requested scope count, including nonmatching intermediates. A private or unlisted intermediate prunes its branch before counting or matching grandchildren. An earlier positive match cannot hide a scope overflow. Cycles/conflicting identities return CQL_DATA_INVALID; overflow returns CQL_QUERY_LIMIT, with no partial result. See [complete semantics and native evidence](CQL_DESCENDANT_CONTRACT.md).

SQLite owns a recursive CTE and connection-local typed validation callbacks. Neo owns quantified paths with inline pruning and bounded distinct endpoint states; separate projection MATCH scopes permit self-loop validation. Neo requires5.9+ and is certified on5.26.12; it retains explicit read-committed semantics. Mongo owns flat depth-bounded breadth lookups under the same snapshot as membership validation. Protected error outcomes survive paging and earlier nonmatching descendant clauses; stage reservations bound compilation before lookup-tree allocation. Final220 unit,61 native and109 joint controls pass unskipped, including compiler-budget reservation.

Direct-child HTTP groups are implemented under the shared filter budget and server actor binding. Descendant HTTP groups, additional cross-store relationship controls and the remaining projections/aggregates/joins/federation work remain open in [the roadmap](CQL_COMPLETION_ROADMAP.md). The generic SDK contract always performs actual-adapter capability/bounds readmission before dispatch.
