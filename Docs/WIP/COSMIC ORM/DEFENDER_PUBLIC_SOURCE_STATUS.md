# OpenZeppelin Defender public source status

4 November 2026. The existing provider targets the hosted Defender API
and configures account credentials. OpenZeppelin documents 1 July 2026 as
the final shutdown date and directs users to its open-source Relayer and
Monitor tools.

Keep hosted Defender outside active CQL admission. A successor profile
requires an explicitly scoped Relayer or Monitor service, a supported
client contract, and read access and identity verification. Historical
Defender exports require separate qualification.

[OpenZeppelin Defender lifecycle](https://docs.openzeppelin.com/defender/faq)
