## Initial source gap

Before the initial implementation, the BootLoader-selected `Neo4jOASIS` provider did not implement `ICosmicQueryStorageProvider`. `Neo4jOASIS2` and Aura are separate implementations; their existence does not certify this provider.

`Neo4jOASIS.HolonSnapshot.cs` owns the transactional holon write path used by ordinary saves, conditional writes and committed replica application. Its `HolonSnapshotRow` currently projects Id, Name, Description, the string HolonType, SnapshotJson, metadata lookup tokens and the provider revision. SnapshotJson contains the richer canonical record. Existing metadata lookup tokens intentionally implement stringified legacy key/value equality; they cannot supply CQL's typed numeric, missing/null or nested-path semantics.

## Required implementation

1. Define one typed native query projection derived from the canonical snapshot. Update that projection in the existing transaction and locked write owner; cover ordinary, conditional, soft/hard delete, replica and import routes. Do not admit predicates against fields that can be stale or absent on historical records.
2. Upgrade existing snapshots with an explicit, restart-safe projection/schema version. Recheck the authoritative snapshot under its write lock before publishing a projection. Concurrent writes must not install an older projection after a newer save. Corrupt historical data must produce an actionable error rather than disappear from query results.
3. Add the shared provider contract, capability profile and a parameterized Cypher translator. Share the common CQL planner and immutable expression representation. Preserve boolean/null semantics, exact typed domains, ordinal strings, field comparisons, deterministic ordering and paging. A stringified metadata token is not a typed match.
4. Enforce pre-I/O admission, cancellation, native deadline, parameter/work/result/payload limits and deterministic resource errors. Read and detach leaf records from SnapshotJson through the existing canonical decoder. Never fetch all records and evaluate the CQL predicate in application memory.
5. Extend the existing reusable native Neo4j environment and conformance suite: persisted typed metadata, malformed/wrong-type values, missing versus null, quoted keys, field comparisons, ordering/ties, scope rejection, cancellation, budgets, upgrade/restart and concurrent-write projection consistency. Keep provider-local leaf execution distinct from still-open authenticated WEB4 routing, child hydration and federated query semantics.
