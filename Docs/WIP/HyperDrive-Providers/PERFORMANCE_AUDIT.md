# OPORTAL and HyperDrive performance audit

14 November 2026, Cancun. Performance is the top priority during provider implementation and qualification. This audit is in progress.

| Path | Finding | Evidence and status |

Switch the portal after the route ships and measure signed-in latency and payload size. |

15 November Cancun time. The compact routes reduce the HTTP response and avoid file DTO projection. Provider-read costs remain open. The file holon stores file bytes inside metadata, and the current owner selector materializes matched holons including that data. The wallet summary likewise loads complete wallet records from storage. Measure the provider payload separately when qualifying these routes, including owners with many unrelated holons and large stored files.

15 November Cancun time. Shared shallow graph projection now skips the graph lookup tables and per-root traversal when the requested depth cannot include children. The existing record clone and empty Children result are preserved. The [focused native latency and parity run](https://github.com/NextGenSoftwareUK/OASIS/actions/runs/43683969960) passed on MongoDB and SQLite. Each returned the same eight roots, with 8 versus 104 materialized nodes. Collection p95 was 27.958 ms shallow and 252.963 ms recursive on MongoDB, and 4.471 ms shallow and 169.044 ms recursive on SQLite. Point-read RoundRobin served 20 reads per provider at 2.243 ms p95. These timings describe the tested fixture and do not isolate the contribution of this patch across different runners. Provider byte projection for the Files count remains open.

15 November Cancun time. WEB4 legacy save and delete authorization and file download authorization use the root identity or access metadata. Existing legacy soft delete and file metadata update re-save the loaded holon using the child-saving contract. These five write paths now explicitly request children. STAR ZomeBase already passes its child preference to HolonManager.

15 November Cancun time. The shallow-read caller correction passed eight Legacy MongoDB soft-delete variants across typed and untyped APIs, synchronous and asynchronous calls, and ID and provider-key selection. File metadata update retained its embedded child and persisted the new name. [Typed and file write evidence](https://github.com/NextGenSoftwareUK/OASIS/actions/runs/43686106494/job/132726808041).

15 November Cancun time. The dashboard Messages card reads the default 50-message page, counts unread flags on outgoing messages, and cannot count older incoming messages. The task branch adds a two-field summary that counts the full deduplicated inbox and outbox and treats only unread received messages as unread. The route omits message content and avoids the list sort. Provider reads still load the durable message bodies. [Native SQLite qualification](https://github.com/NextGenSoftwareUK/OASIS/actions/runs/43686768595/job/132728770627) passed. The list page returned 50 outgoing messages. The summary counted all 53 participating messages, deduplicated the self-message, excluded unrelated records and reported one unread received message.
