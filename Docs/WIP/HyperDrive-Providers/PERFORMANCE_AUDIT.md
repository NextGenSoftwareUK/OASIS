# OPORTAL and HyperDrive performance audit

14 November 2026, Cancun. Performance is the top priority during provider implementation and qualification. This audit is in progress.

| Path | Finding | Evidence and status |
| --- | --- | --- |
| Signed-in dashboard startup | Multiple startup events requested the same data for one session. Session-scoped deduplication is live. | Controlled browser requests fell from 37 attempts to 20 distinct calls on the later preview. Signed-in production timings remain open. |
| Dashboard Data count | The count only uses returned roots. Traversal previously materialized their nested graph. The live client requests shallow results. | [Native MongoDB and SQLite](https://github.com/NextGenSoftwareUK/OASIS/actions/runs/43673759219/job/132689471380) returned the same eight IDs and materialized 8 versus 104 nodes. MongoDB collection p95 was 38.010 ms shallow and 341.025 ms recursive. SQLite was 7.528 ms and 223.694 ms. |
| Shared holon defaults | HolonManager and WEB4 on the task branch default to shallow reads. Explicit graph operations keep their traversal and depth controls. | Native point and parent reads, one-level expansion and eager parity passed on both stores. WEB4 binding and remaining callers are under audit. Three COSMIC graph consumers now opt in explicitly. |
| Subscription | Opening the popup fetched unrelated tabs. Usage also waited for pricing and statements before rendering. The live portal now loads the selected tab and renders usage independently. | Controlled production verified the usage summary was visible while pricing and statements were held for five seconds. |
| Popup fragment loading | Subscription and Data previously bound after all optional modal fragments finished. The new preview binds them as their own fragments arrive. | A controlled browser reached the signed-in dashboard and Subscription deep link in 3.026 seconds while an unrelated fragment was delayed by 25 seconds. Data opened at its own route with that fragment still pending. Production serves the assets from 63f7d0f. Signed-in production timings remain open. |
| Dashboard map | The map count waited for GeoNFTs and the parser omitted WEB4's totalVisits field. | Candidate 9bc09d9 passed controlled response-order checks. It preserves current and earlier visit fields and displays the visit count independently. The backend map and karma fixes await exact WEB4 rollout. |
| Dashboard Files | The dashboard currently fetches the full file list. The task branch has an authenticated count route that shares the existing file-selection rules and skips list DTO projection. SQLite now applies metadata filtering before mapping holons. | [Focused native SQLite run](https://github.com/NextGenSoftwareUK/OASIS/actions/runs/43677992984) covers count/list parity, avatar isolation and metadata materialization. Switch the portal after the route ships and measure signed-in latency and payload size. |
| Other dashboard counters | Games, messages, gifts and wallet counters currently consume complete lists. Subscription app-owner detail also requests usage, settings and billing in sequence. | Identify which endpoints support scoped counts or projections and compare real payload size and signed-in latency. Confirm each app-owner route's authorization before parallelizing its reads. |
| HyperDrive routing | Native timings cover warm direct provider and request-scoped reads. Hosted behavior also includes authentication, network time, graph materialization and deployment topology. | [Routing evidence and open hosted checks](PRIORITY_HYPERDRIVE_ROUTING.md). Compare the same reads and payloads before and after changes, recording the provider that served each result. |

Preserve the measured browser, HTTP and native behavior in [current status](CURRENT_STATUS.md). Record disposable environments and artifact removal in the [cleanup ledger](WORKSPACE_CLEANUP_LEDGER.md).
