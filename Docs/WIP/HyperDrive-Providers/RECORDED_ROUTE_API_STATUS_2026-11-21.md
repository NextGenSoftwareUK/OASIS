Summary holons use custom type OASIS.MapRoute.v1 and parent Guid(SHA256(UTF8("oasis:map-routes:{owner:D}"))[0..16]). Geometry holons use OASIS.MapRouteGeometry.v1, ID Guid(SHA256(UTF8("oasis:map-route-geometry:{route:D}"))[0..16]), and parent route ID. These use .NET Guid byte ordering. Both share the server-authenticated creator and explicit visibility. Payload metadata is JSON: summary contains SourceApp/SourceRouteId/PointCount/SegmentCount; geometry contains arrays of connected point segments. No karma or reward fields are accepted.
