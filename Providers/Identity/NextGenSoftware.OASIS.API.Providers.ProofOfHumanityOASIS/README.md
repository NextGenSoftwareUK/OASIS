# ProofOfHumanityOASIS

Proof of Humanity - on-chain sybil-resistant human registry.

Part of the [OASIS HOT-Swappable Provider Architecture](https://oasisomniverse.one).

## Usage

Register in your `OASIS_DNA.json`:

```json
{
  "DefaultProviders": ["ProofOfHumanityOASIS"]
}
```
