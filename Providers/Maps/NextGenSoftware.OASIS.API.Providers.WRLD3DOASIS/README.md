# NextGen Software WEB4 OASIS API WRLD3D OASIS Provider

This compatibility package preserves the legacy WRLD 3D map contract used by Our World. It has no native map backend adapter. Map operation methods return `false` to report that the requested action was unavailable.

[Our World source and documentation](https://github.com/NextGenSoftwareUK/Our-World-OASIS-API-HoloNET-HoloUnity-And-.NET-HDK)
