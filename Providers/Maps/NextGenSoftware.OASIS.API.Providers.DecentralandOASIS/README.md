# DecentralandOASIS

Decentraland - Ethereum-based 3D virtual world and metaverse platform.

Part of the [OASIS HOT-Swappable Provider Architecture](https://oasisomniverse.one).

## Usage

Register in your `OASIS_DNA.json`:

```json
{
  "DefaultProviders": ["DecentralandOASIS"]
}
```
