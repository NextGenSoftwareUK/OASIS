# ReadyPlayerMeOASIS

Ready Player Me - cross-game avatar platform for the metaverse.

Part of the [OASIS HOT-Swappable Provider Architecture](https://oasisomniverse.one).

## Usage

Register in your `OASIS_DNA.json`:

```json
{
  "DefaultProviders": ["ReadyPlayerMeOASIS"]
}
```
