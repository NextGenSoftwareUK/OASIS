# TheSandboxOASIS

The Sandbox - blockchain-based virtual gaming world and metaverse.

Part of the [OASIS HOT-Swappable Provider Architecture](https://oasisomniverse.one).

## Usage

Register in your `OASIS_DNA.json`:

```json
{
  "DefaultProviders": ["TheSandboxOASIS"]
}
```
