# OpenZeppelinDefenderOASIS

OpenZeppelin Defender - smart contract security automation platform.

Part of the [OASIS HOT-Swappable Provider Architecture](https://oasisomniverse.one).

## Usage

Register in your `OASIS_DNA.json`:

```json
{
  "DefaultProviders": ["OpenZeppelinDefenderOASIS"]
}
```
