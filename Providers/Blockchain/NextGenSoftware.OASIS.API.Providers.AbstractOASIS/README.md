# NextGen Software WEB4 OASIS API Abstract OASIS Provider

WEB4 OASIS API Abstract OASIS Provider is one of the many WEB2/WEB3 providers that plug in and integrate into the OASIS.

Abstract is a consumer-focused EVM Layer 2 blockchain purpose-built for gaming and NFT applications, settled on Ethereum. This provider stores OASIS holons, avatars, and NFTs on Abstract Mainnet and participates in the broader EVM ecosystem. Fully integrated with the OASIS HOT-Swappable Provider Architecture — switch to or from Abstract at runtime with zero code changes.
