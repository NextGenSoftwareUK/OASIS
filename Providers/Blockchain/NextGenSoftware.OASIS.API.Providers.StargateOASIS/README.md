# StargateOASIS

Stargate - cross-chain liquidity protocol built on LayerZero.

Part of the [OASIS HOT-Swappable Provider Architecture](https://oasisomniverse.one).

## Usage

Register in your `OASIS_DNA.json`:

```json
{
  "DefaultProviders": ["StargateOASIS"]
}
```
