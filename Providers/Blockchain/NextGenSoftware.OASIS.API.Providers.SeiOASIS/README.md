# NextGen Software WEB4 OASIS API Sei OASIS Provider

WEB4 OASIS API Sei OASIS Provider is one of the many WEB2/WEB3 providers that plug in and integrate into the OASIS.

Sei is a high-performance EVM-compatible Layer-1 blockchain with 400ms finality, optimised for trading and real-time applications. This provider stores OASIS holons, avatars, and NFTs on Sei Mainnet (chain ID 1329), taking advantage of Sei's ultra-low latency for responsive OASIS interactions. Fully integrated with the OASIS HOT-Swappable Provider Architecture — switch to or from Sei at runtime with zero code changes.
