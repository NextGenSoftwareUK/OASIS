# NextGen Software WEB4 OASIS API Ceramic OASIS Provider

WEB4 OASIS API Ceramic OASIS Provider is one of the many WEB2/WEB3 providers that plug in and integrate into the OASIS.

Ceramic Network is a decentralised data protocol for mutable, verifiable streams anchored to blockchains. This provider connects to Ceramic via the HTTP API, mapping DIDs to OASIS Avatars and Ceramic streams to OASIS Holons, with support for ComposeDB queries. Fully integrated with the OASIS HOT-Swappable Provider Architecture — switch to or from Ceramic at runtime with zero code changes.
