# deBridgeOASIS

deBridge - cross-chain interoperability and liquidity transfer.

Part of the [OASIS HOT-Swappable Provider Architecture](https://oasisomniverse.one).

## Usage

Register in your `OASIS_DNA.json`:

```json
{
  "DefaultProviders": ["deBridgeOASIS"]
}
```
