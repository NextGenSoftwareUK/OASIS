# NextGen Software WEB4 OASIS API Algorand OASIS Provider

WEB4 OASIS API Algorand OASIS Provider is one of the many WEB2/WEB3 providers that plug in and integrate into the OASIS.

Algorand is a pure Proof-of-Stake Layer-1 blockchain renowned for its fast finality, low fees, and carbon-neutral footprint. This provider connects to the Algorand network via the Algod REST API (Algonode.io), mapping Algorand accounts to OASIS Avatars and transactions/ASAs to OASIS Holons. Fully integrated with the OASIS HOT-Swappable Provider Architecture — switch to or from Algorand at runtime with zero code changes.
