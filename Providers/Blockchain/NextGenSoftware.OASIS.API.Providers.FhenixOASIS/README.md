# FhenixOASIS

OASIS provider for [Fhenix](https://www.fhenix.io/) — the first EVM-compatible Layer 2 powered by Fully Homomorphic Encryption (FHE), enabling privacy-preserving smart contracts without revealing private data on-chain.

Part of the [OASIS Omniverse](https://oasisomniverse.one) HOT-Swappable Provider Architecture.
