# NextGen Software WEB4 OASIS API Filecoin OASIS Provider

WEB4 OASIS API Filecoin OASIS Provider is one of the many WEB2/WEB3 providers that plug in and integrate into the OASIS.

Filecoin is the world's largest decentralised storage network, combining verifiable storage proofs with a native blockchain. This provider connects via the Lotus JSON-RPC API (using the Glif.io public endpoint), mapping Filecoin addresses to OASIS Avatars and storage deals/CIDs to OASIS Holons. Fully integrated with the OASIS HOT-Swappable Provider Architecture — switch to or from Filecoin at runtime with zero code changes.
