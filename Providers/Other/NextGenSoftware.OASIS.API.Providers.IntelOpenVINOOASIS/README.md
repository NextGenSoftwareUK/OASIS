# IntelOpenVINOOASIS

Intel OpenVINO - on-premise AI inference runtime for CPU/GPU/VPU.

Part of the [OASIS HOT-Swappable Provider Architecture](https://oasisomniverse.one).

## Usage

Register in your `OASIS_DNA.json`:

```json
{
  "DefaultProviders": ["IntelOpenVINOOASIS"]
}
```
