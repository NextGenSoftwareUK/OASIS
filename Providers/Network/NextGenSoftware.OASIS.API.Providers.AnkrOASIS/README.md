# AnkrOASIS

Ankr - multi-chain RPC gateway and staking infrastructure.

Part of the [OASIS HOT-Swappable Provider Architecture](https://oasisomniverse.one).

## Usage

Register in your `OASIS_DNA.json`:

```json
{
  "DefaultProviders": ["AnkrOASIS"]
}
```
