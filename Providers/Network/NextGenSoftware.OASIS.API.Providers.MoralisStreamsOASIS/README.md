# MoralisStreamsOASIS

Moralis Streams - real-time blockchain event webhooks.

Part of the [OASIS HOT-Swappable Provider Architecture](https://oasisomniverse.one).

## Usage

Register in your `OASIS_DNA.json`:

```json
{
  "DefaultProviders": ["MoralisStreamsOASIS"]
}
```
