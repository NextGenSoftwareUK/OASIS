# NextGen Software WEB4 OASIS API IPFS OASIS Provider

WEB4 OASIS API IPFS OASIS Provider is one of the many WEB2/WEB3 providers that plug in and integtate into the OASIS.

## Read acknowledgements

Successful point reads report `IsLoaded=true` and `LoadedCount=1`. Collection, parent, metadata, export, search and nearby results count returned roots, not nested children or backend requests. A successful empty collection remains loaded with count zero; missing point records and failed reads do not claim loaded records. Nearby filtering recomputes the returned count and clears it on failure.

These counts do not change canonical records, encrypted storage, query selection, ownership filters or version/graph semantics. They are logical result counts, not an IPFS resource or fee meter. Current controlled and retained Kubo evidence, plus remaining interface/durability/hosted/HyperDrive gates, are tracked in `Docs/WIP/HyperDrive-Providers/HYPERDRIVE_V2_CURRENT_RELEASE_GATES.md`.
