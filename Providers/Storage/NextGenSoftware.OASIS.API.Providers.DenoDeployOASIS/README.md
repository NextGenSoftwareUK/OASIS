# DenoDeployOASIS

Deno Deploy - globally distributed serverless JavaScript runtime.

Part of the [OASIS HOT-Swappable Provider Architecture](https://oasisomniverse.one).

## Usage

Register in your `OASIS_DNA.json`:

```json
{
  "DefaultProviders": ["DenoDeployOASIS"]
}
```
