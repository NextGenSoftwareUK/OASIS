# NextGen Software WEB4 OASIS API BlueSky OASIS Provider

WEB4 OASIS API BlueSky OASIS Provider is one of the many WEB2/WEB3 providers that plug in and integrate into the OASIS.

BlueSky is a decentralised social network built on the AT Protocol (atproto), offering an open, federated alternative to centralised social media. This provider maps BlueSky user profiles to OASIS Avatars and posts (app.bsky.feed.post records) to OASIS Holons, with authentication via app passwords or OAuth. Fully integrated with the OASIS HOT-Swappable Provider Architecture — switch to or from BlueSky at runtime with zero code changes.
