# NextGen Software WEB4 OASIS API Matrix OASIS Provider

WEB4 OASIS API Matrix OASIS Provider is one of the many WEB2/WEB3 providers that plug in and integrate into the OASIS.

Matrix is an open, decentralised protocol for encrypted real-time communications, used by Element, Synapse, and many other clients and homeservers. This provider maps Matrix users to OASIS Avatars and room events (messages) to OASIS Holons, supporting any homeserver via the MATRIX_HOMESERVER environment variable. Fully integrated with the OASIS HOT-Swappable Provider Architecture — switch to or from Matrix at runtime with zero code changes.
