# GaladrielOASIS

Galadriel - Layer 1 blockchain for on-chain AI applications.

Part of the [OASIS HOT-Swappable Provider Architecture](https://oasisomniverse.one).

## Usage

Register in your `OASIS_DNA.json`:

```json
{
  "DefaultProviders": ["GaladrielOASIS"]
}
```
